# Excel → Power BI Granularizer

A small web app that turns a messy spreadsheet (cross-tabs, multi-row headers,
section banners, subtotal rows, repeating metric columns) into a **tidy, granular,
long-format table** ready for Power BI — plus a transformation log and a
reconciliation check so you can trust the output.

It also **traces formulas** back to their source cells/sheets for the common,
resolvable formula patterns.

## What it does (and does not) do

- **Deterministic reshape.** The same file + same settings always produce the same
  table. No numbers are computed by AI; values come straight from the cells.
- **Detect → confirm → reshape.** The app guesses the layout, but *you* confirm or
  correct the header rows, identifier columns, and hierarchy before it reshapes. This
  is how it copes with files that all look different.
- **Honest about formulas.** It reads each cell's formula text *and* its stored value.
  It can follow direct references, ranges, `SUM/SUMIF(S)`, `AVERAGE`, `COUNT(IF(S))`,
  `VLOOKUP`, `INDEX/MATCH`, `XLOOKUP`. It **flags** what it cannot statically follow
  (`INDIRECT`, `OFFSET`, dynamic-array spill, full recalculation) rather than guessing.
- **Caveat — uncached formulas.** If a file was never calculated/saved by Excel (e.g.
  generated by a script), formula cells have no stored value and read as blank. Open and
  save the file in Excel once to populate values, or rely on formula tracing.

## Run locally

```bash
pip install -r requirements.txt
python make_sample.py          # optional: creates sample_workbook.xlsx to test with
streamlit run app.py
```

The app opens at http://localhost:8501.

## Deploy a shareable link (your step)

I can't deploy for you — it uses your own GitHub and Streamlit accounts. Once those
exist, it takes a few minutes:

1. Put this folder in a **GitHub repository** (must contain `app.py`,
   `engine_core.py`, `formula_trace.py`, `requirements.txt`).
2. Go to **share.streamlit.io**, sign in with GitHub, click **New app**, select your
   repo and `app.py`, and **Deploy**. You get a public URL like
   `https://<your-app>.streamlit.app`.
3. **Restrict access** (important — this is internal workforce data): open the app's
   **Settings → Sharing** and limit viewers to specific email addresses instead of
   leaving it public.

## Files

| File | Purpose |
|------|---------|
| `app.py` | Streamlit UI (upload, confirm, preview, download, trace) |
| `engine_core.py` | Loading, layout detection, reshape, reconciliation, export |
| `formula_trace.py` | Formula reference parsing and source tracing |
| `make_sample.py` | Generates a test workbook |
| `requirements.txt` | Dependencies |
